# Brief: ejecutar plan QOL y avisos de versión

- Resultado: recorridos claros para equipos, proyectos, tareas y recursos, FAQ ampliada, changelog completo y aviso de novedades por versión.
- Alcance: interfaz CMS, modelo/API si hace falta, navegación, ayuda, changelog, versión, almacenamiento local y pruebas.
- Exclusiones: avisos por correo o teléfono, almacenamiento de archivos binarios y carga de datos reales sin confirmación.
- Autoridad: cambios locales y pruebas; publicación externa no autorizada en este pedido.
- Evidencia: pruebas unitarias, integración y UI, build Cloudflare, auditoría visual en escritorio y celular, y diff limpio.
- Evidencia: aviso automático una vez por versión y reapertura manual desde Cambios.
- Evidencia: cada nota muestra versión y las fechas provienen de commits reales.
- Stop: terminar cuando las fases implementables sin proveedor externo estén verificadas y lo restante quede explícitamente bloqueado.
- Esfuerzo: alto por impacto transversal en datos, permisos, navegación y experiencia móvil.
