Outcome: Finanzas permite reemplazar la planilla con un flujo compacto, claro y completo para cuentas, cargos, cobros, pendientes y cierre mensual.
Scope: Interfaz, modelo, API y pruebas de Finanzas en VoluntariosFSB; usar el Excel 2026 como referencia funcional.
Excluded: Importar datos del Excel, modificar información real, publicar o cambiar permisos.
Authority: Lectura del Excel y edición local del proyecto; la publicación requiere otra autorización.
Evidence: Inventario Excel contra sistema, mediciones de controles actuales, pruebas funcionales, captura visual en escritorio y móvil, y auditoría final.
Stop condition: Todos los datos y tareas relevantes del Excel tienen un flujo explícito o una limitación documentada, sin duplicación visible ni desbordes.
Tool route: Artifact Tool para leer el Excel, navegador para medir, apply_patch para editar, pruebas del proyecto para validar.
Model effort: Alto, por cruce de contrato financiero, UX, responsive y privacidad.
Risks: Cambiar semántica contable, perder información editable o mezclar permisos con presentación.
First checkpoint: Mapa de hojas, columnas, fórmulas y acciones del Excel comparado con el modelo y la pantalla actuales.
