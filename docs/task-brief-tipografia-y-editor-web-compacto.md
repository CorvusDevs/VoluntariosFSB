Outcome: League Gothic puede elegirse en todos los títulos breves pertinentes, “Sibshops” queda correctamente presentado y las listas del editor son compactas y fáciles de recorrer.
Scope: Modelo y editor de Página web, maqueta de vista previa, CSS y pruebas asociadas en VoluntariosFSB.
Excluded: Textos largos, navegación, botones y campos operativos en League Gothic; publicación; aletea.org principal; cambios de datos privados.
Authority: Cambios y verificación local. Cualquier despliegue requiere confirmación nueva.
Evidence: Diagnóstico medido, pruebas del modelo y UI, vista escritorio y teléfono sin desborde, y comprobación visual local.
Stop condition: Los selectores tipográficos aparecen solo donde aportan jerarquía, “Sibshops” no queda pegado, y las colecciones se editan con resúmenes plegables compactos.
Tool route: Inspección de fuente, medición en navegador, parches acotados, Vitest y captura local.
Model effort: Alto por cambios coordinados de modelo, render y UX sin perder contenido existente.
Risks: Incompatibilidad con borradores anteriores, exceso de League Gothic y controles plegables que oculten estado importante.
First checkpoint: Identificar las claves tipográficas actuales y medir la altura y el ancho efectivos de una tarjeta expandida.
