Outcome: La página pública completa se edita visualmente desde el gestor, incluidas fotos optimizadas, enlaces y redes sociales.
Scope: Modelo y API de Página web, editor visual, vista previa pública, estilos, pruebas y referencia del PDF de agosto de 2026.
Excluded: Publicación en gestor.aletea.org, prueba.aletea.org o aletea.org, DNS y migración de producción.
Authority: Ediciones locales y pruebas. Toda publicación externa necesita autorización posterior.
Evidence: Recomendaciones del PDF trazadas a secciones, guardado y recarga sin pérdida, imágenes WebP/JPEG optimizadas, enlaces seguros, escritorio y móvil sin desbordamiento.
Stop condition: Cada bloque público es visualmente editable y los controles simples cubren imágenes, enlaces, orden, visibilidad y redes.
Tool route: PDF y referencias, modelo/API actual, prototipo local, pruebas unitarias e integración, inspección visual en navegador.
Model effort: Alto, por cambio coordinado de contenido, UX, almacenamiento y página pública.
Risks: Tamaño de imágenes, compatibilidad del servidor cPanel, URLs externas, accesibilidad y demasiadas opciones visibles a la vez.
First checkpoint: Probar el contrato actual de datos e imágenes antes de ampliar el modelo.
