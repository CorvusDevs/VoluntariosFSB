# Brief: formulario de actividad más simple

- Resultado: crear una actividad exige pocas decisiones visibles y conserva las opciones avanzadas cuando hacen falta.
- Alcance: formulario de actividad, patrones equivalentes de agenda, estilos, ayuda, novedades y pruebas del gestor.
- Exclusiones: contratos de API, migraciones, permisos, datos existentes y página pública.
- Autoridad: editar, probar, auditar, confirmar GitHub y publicar el gestor en cPanel.
- Evidencia: medición antes y después, pruebas enfocadas y completas, escritorio y 390 px, auditorías, sello vivo y hashes.
- Stop: no publicar si hay recortes, campos inaccesibles, regresiones de recurrencia o sellos distintos.
- Modelo: esfuerzo medio para implementación y alto para cierre visual y publicación.
