Outcome: Accesos usa nombres comprensibles y muestra si cada requisito está cumplido, con una acción directa para completar los pendientes.
Scope: editor de Accesos, estilos, ayuda, cambios, versión, pruebas, paquete cPanel y publicación en gestor.aletea.org.
Excluded: cambiar las reglas de autorización, conceder permisos a usuarios reales durante el desarrollo, publicar la web pública o publicar el código fuente.
Authority: se permiten ediciones locales, pruebas, empaquetado y publicación del gestor solicitada en este turno.
Evidence: pruebas de nombres, requisitos cumplidos y pendientes, acciones de perfil y Finanzas, auditoría visual, pruebas completas, hashes y versión pública.
Stop condition: cada requisito sensible se calcula con datos reales y puede resolverse desde Accesos sin navegar a otra pantalla.
Model effort: alto por autorización, escalamiento de perfiles y despliegue.
