# Brief: jerarquía del menú institucional

Outcome: Página web contiene solo sus dos herramientas y Organización reúne Áreas, Formularios y Biblioteca.
Scope: navegación de escritorio y móvil, preferencias de colapso, icono de Contenido y pruebas.
Excluded: cambiar permisos, destinos, contenido o publicar en producción.
Authority: cambios locales; cualquier despliegue requiere confirmación nueva.
Evidence: grupos correctos, iconos presentes, colapso persistente, pruebas y revisión visual móvil.
Stop condition: ningún destino institucional aparece dentro de Página web y Contenido tiene icono.
Tool route: instantánea de configuración, parches acotados, Vitest y navegador local.
Model effort: medio.
