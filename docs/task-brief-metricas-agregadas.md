Outcome: Administración comprende el alcance de la página pública con un resumen visual de visitas, páginas y acciones, sin perfiles personales.
Scope: Modelo de configuración, API CMS, pantalla de Página web, estilos, pruebas y plan operativo local.
Excluded: Activar Cloudflare Web Analytics, consultar producción, cookies publicitarias, huellas digitales, perfiles de personas y publicación.
Authority: Ediciones y validación locales. Toda activación, credencial o despliegue requiere autorización posterior.
Evidence: Etapa 2 sigue en verde, datos agregados no contienen identificadores, estados vacíos son claros y la suite completa compila.
Stop condition: El gestor deja preparada y entendible la lectura de métricas agregadas, manteniendo el proveedor apagado y sin inventar datos reales.
Tool route: Inspección focalizada, apply_patch, Vitest, compilación Cloudflare y auditoría estática.
Model effort: Alto, por privacidad, claridad de datos y compatibilidad con el CMS existente.
Risks: Presentar cifras simuladas como reales, activar seguimiento por accidente o mezclar métricas públicas con respuestas de formularios.
First checkpoint: Reauditar la etapa de privacidad y localizar el modelo actual de operación y analítica antes de diseñar la interfaz.
