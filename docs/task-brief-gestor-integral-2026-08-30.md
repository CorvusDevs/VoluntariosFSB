Outcome: el gestor permite encontrar, ejecutar y auditar trabajo institucional de punta a punta desde escritorio o celular, con datos y avisos actualizados al momento.
Scope: centro de control, tareas y cierres, unidades, formularios, accesos, navegación móvil, búsqueda, estados, actualización, pruebas, build y despliegue cPanel.
Excluded: rediseñar la página pública oficial, cambiar DNS, habilitar pagos reales o publicar secretos y configuración propia del servidor.
Authority: editar, migrar, probar, empaquetar, publicar gestor y página de prueba por el flujo SFTP autorizado, y verificar el estado vivo.
Evidence: pruebas focalizadas y suite completa, medidas DOM 1440x900 y 390x844, flujos reales de cierre/formulario/permisos, auditoría de dist, sello y SHA-256 vivos, rutas/API y archivos protegidos.
Stop condition: las ocho mejoras están demostradas una por una, el build local es coherente, ambas sesiones de actualización muestran el mismo sello y el despliegue vivo pasa las puertas del proyecto.
Tool route: inspección acotada, fixture local, Vitest, navegador, scripts oficiales preparar/publicar/verificar y auditoría Git antes de cualquier push.
Model effort: alto, porque combina UX, permisos, persistencia, actualización y publicación coordinada.
Risks: mezclar cambios previos no auditados, filtrar datos, romper permisos, servir módulos de sellos distintos o sobrescribir `.htaccess`.
First checkpoint: inventariar qué parte de cada recomendación ya existe y qué evidencia falta antes de editar.
