Outcome: Publicar Cartas membretadas en gestor.aletea.org y después publicar un interlineado más cómodo para League Gothic en el gestor y prueba.aletea.org.
Scope: Gestor cPanel, vista previa de Página web, sitio público de prueba, sellos de versión, caché y verificación visual en escritorio y teléfono.
Excluded: aletea.org, WordPress, DNS, Git remoto, cambios destructivos de datos y revocar el token temporal de cPanel.
Authority: Construir, subir, extraer y reiniciar los destinos autorizados. Mantener una ruta de reversión con los paquetes anteriores.
Evidence: Pruebas completas, builds, medición del estilo calculado antes y después, ausencia de desborde horizontal, versión en vivo y archivos de destino coincidentes.
Stop condition: Cartas membretadas aparece en el gestor y el título expresivo tiene separación vertical legible en la vista previa y en prueba.aletea.org, sin afectar la página principal.
Tool route: Shell local, API de cPanel para carga, sesión autenticada para extracción si hace falta y navegador para verificación visual.
Model effort: Alto por doble publicación y riesgo de caché.
Risks: Publicación parcial, mezcla de versiones, caché antigua, interlineado excesivo y diferencias entre vista previa y sitio público.
First checkpoint: Publicar primero el gestor ya auditado y verificar su sello antes de modificar el interlineado.
